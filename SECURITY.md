# Security Policy

## Supported releases

Security fixes are applied to the current `main` branch. Older build artifacts may no longer be supported.

## Reporting a vulnerability

Please do not publish exploitable details, proof-of-concept code, or private-world/server information in a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled. If it is not available, contact the repository maintainer privately through GitHub and request a secure reporting channel. Include the affected commit or build version, impact, and steps to reproduce in a private report.

Please allow time for triage and a fix before publicly disclosing details.
